# fly_in

## Run solver

```bash
python3 fly_in.py maps/hard/01_maze_nightmare.txt
```

or:

```bash
make run
```

## Run pygame visualizer

Install pygame first:

```bash
pip install pygame
```

Run:

```bash
python3 visualizer.py maps/hard/01_maze_nightmare.txt
```

or:

```bash
make visual
```

### Visualizer controls

- `Space`: pause/resume
- `Right Arrow`: single-step while paused
- `Up/Down`: increase/decrease simulation speed
- `R`: reset simulation
- `Q` or `Esc`: quit
